# Inkwell & Page — Bookstore Homepage

A static frontend homepage for a fictional independent bookstore. Plain HTML + CSS, no build step, no dependencies.

## Run it

Open `index.html` directly in a browser, or serve it:

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```

## What's inside

- `index.html` — the full homepage: hero, staff picks, categories, story section, newsletter, footer
- `styles.css` — all styling (warm paper/terracotta palette, Playfair Display + Inter via Google Fonts)

Photos are hotlinked from [Unsplash](https://unsplash.com) (free to use under the Unsplash license), so an internet connection is needed for the images to load.
